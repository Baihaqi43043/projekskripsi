1. RINGKASAN FILE DATA SAAT INI (FOLDER: data/raw/)
--------------------------------------------------------------------------------
A. data/raw/aceh_utara_agroklimat_harian.csv
   - Jumlah data : 43.840 baris (20 lokasi x 2.192 hari, 1 Jan 2020 - 31 Des 2025)
   - Sumber      : NASA POWER API (https://power.larc.nasa.gov/api/temporal/daily/point)
                   Community: AG (Agroclimatology).
   - Kolom       : id_lokasi, tanggal (YYYY-MM-DD), tahun, bulan, curah_hujan,
                   suhu_rata_rata, suhu_maksimal, suhu_minimum,
                   kelembaban_rata_rata, lama_penyinaran.
   - Status      : DATA RIIL (100% terisi dari NASA POWER API untuk 20 kecamatan).
                   Diunduh ulang 24 Nov 2026 via `python fetch_data.py --only climate`;
                   nilainya identik dengan split 5 lokasi lama (selisih 0,0000 di semua kolom).
   - Split LSTM (data/raw/lstm/):
     * training/training.csv : 5 lokasi (L001-L005), 2020-2024, 9.135 baris
     * testing/testing.csv   : 5 lokasi (L001-L005), 2025, 1.825 baris
     * Dipakai BiLSTM cuaca (notebook, train_bilstm_weather.py, dashboard).
       Folder duplikat `train/` dan salinan `aceh_utara_agroklimat_harian.csv` di dalamnya dihapus.
   - Satuan lama_penyinaran: ALLSKY_SFC_SW_DWN = radiasi (MJ/m2/hari), BUKAN jam/hari.

B. data/raw/aceh_utara_agroklimat_bulanan.csv
   - Jumlah data : 1.440 baris (20 lokasi x 72 bulan, periode Jan 2020 - Des 2025)
   - Sumber      : Agregasi bulanan dari data harian NASA POWER API.
   - Kolom       :
     * id_lokasi             : ID titik pengamatan (L001 - L020)
     * tahun, bulan          : Periode waktu (2020 - 2025, bulan 1 - 12)
     * curah_hujan           : Total curah hujan bulanan (PRECTOTCORR, mm)
     * suhu_rata_rata        : Rata-rata suhu udara bulanan (T2M, °C)
     * suhu_maksimal         : Rata-rata suhu maksimal bulanan (T2M_MAX, °C)
     * suhu_minimum          : Rata-rata suhu minimal bulanan (T2M_MIN, °C)
     * kelembaban_rata_rata  : Rata-rata kelembaban relatif bulanan (RH2M, %)
     * lama_penyinaran       : Rata-rata radiasi penyinaran matahari (ALLSKY_SFC_SW_DWN)
   - Status      : DATA RIIL (100% terisi dari NASA POWER API untuk 20 kecamatan).

C. data/raw/aceh_utara_tanah_statis.csv
   - STATUS FILE : BELUM ADA DI REPO (24 Nov 2026). File lama tidak pernah di-commit dan API
                   SoilGrids sedang tidak merespons. Salin file asli ke data/raw/ atau jalankan
                   `python fetch_data.py --only soil` saat SoilGrids aktif. Kolom baru
                   `sumber_tanah` (SoilGrids/DUMMY) menandai asal data per lokasi.
   - Jumlah data : 20 baris (20 kecamatan di Kabupaten Aceh Utara: L001 - L020)
     Lhoksukon, Matangkuli, Syamtalira Aron, Dewantara, Kuta Makmur, Muara Batu,
     Samudera, Tanah Luas, Nibong, Syamtalira Bayu, Meurah Mulia, Tanah Pasir,
     Lapang, Baktiya, Baktiya Barat, Seunuddon, Tanah Jambo Aye, Langkahan,
     Cot Girek, dan Sawang.
   - Status Isi  :
     * DATA RIIL SoilGrids    : Semua 20 lokasi (L001 - L020) terisi data riil
                                untuk kolom tekstur_tanah, ph_tanah, karbon_organik.
     * KONFIGURASI LOKASI     : lintang, bujur, nama_lokasi, ketinggian_tempat.
     * DATA DUMMY TERSTRUKTUR : nitrogen (0.10-0.90), fosfor (8.5-16.5),
                                kalium (0.22-0.60), drainase (Baik/Rusak), dan
                                risiko_bencana_hama (Rendah/Sedang/Tinggi) dibuat
                                deterministik per id_lokasi (src/data_fetcher.py)
                                untuk menggantikan data lab/Dinas yang belum ada.

D. data/raw/varietas_tanaman.csv
   - STATUS FILE : BELUM ADA DI REPO dan tidak dibuat oleh script mana pun. Belum dipakai kode;
                   perlu disalin dari laptop yang menyusunnya.
   - Jumlah data : 25 baris (25 varietas Padi, Jagung, dan Kedelai).
   - Kolom       : id_varietas, nama_varietas, komoditas, umur_panen_hari,
                   potensi_hasil_ton_ha, ketahanan_hama_skala (1-5),
                   kebutuhan_air (Banyak/Sedang/Sedikit), ketinggian_optimal_mdpl,
                   sumber_status.
   - Status Isi  :
     * Baris 1-10  : Diambil dari Tabel 3.7 PDF proposal.
     * Baris 11-25 : Dummy referensi varietas nasional Kementan/BSIP untuk
                     menggenapi target 25-30 varietas.
