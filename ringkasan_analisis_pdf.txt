2. INTI MASALAH & NOVELTY (KEBARUAN)
--------------------------------------------------------------------------------
- Masalah Utama :
  Mayoritas model rekomendasi tanaman terdahulu masih memakai data statis atau
  model tunggal (single model), sehingga belum menangkap dinamika iklim jangka
  panjang (time-series) dan kompleksitas hubungan non-linear antar variabel.
- Solusi & Novelty :
  Menggabungkan Long Short-Term Memory (LSTM) sebagai temporal feature extractor
  dengan Random Forest (RF) sebagai classifier & decision maker untuk
  merekomendasikan varietas tanaman pangan (Padi, Jagung, Kedelai; 25-30
  varietas) pada konteks agroekologi Provinsi Aceh.


3. ARSITEKTUR MODEL HYBRID (BAB III)
--------------------------------------------------------------------------------
1. Data Collection Layer :
   - Agroklimat (Time-Series, BMKG 2020-2025, bulanan): curah hujan, suhu
     rata-rata, suhu maksimal, suhu minimal, kelembaban rata-rata, lama
     penyinaran.
   - Kondisi Tanah & Lingkungan (Dinas Pertanian Aceh / observasi): tekstur
     tanah, pH, N, P, K, karbon organik, drainase, ketinggian tempat, risiko
     bencana alam & hama.
   - Data Varietas (Kementan RI): nama varietas, umur panen, potensi hasil,
     ketahanan hama, kebutuhan air, ketinggian optimal (25-30 varietas).
2. Data Preprocessing Layer :
   - Cleaning (interpolasi missing values, deteksi outlier IQR), normalisasi
     Min-Max / Z-Score, dan feature engineering.
   - Pembagian data: 80% training, 20% testing (20 titik pengamatan di Aceh Utara).
3. LSTM Module :
   - Input sekuens agroklimat (disebut 60 bulan pada Bagian 3.10).
   - 2 layer LSTM (128 dan 64 units) + dropout -> menghasilkan vektor fitur
     temporal 32 dimensi.
4. Random Forest Module :
   - Input = gabungan vektor temporal LSTM (32-dim) + fitur statis tanah/lokasi.
   - Output = klasifikasi kelas varietas & probabilitas per kelas.
5. Recommendation Engine :
   - Pemeringkatan varietas (Top-K) berdasarkan skor kecocokan + justifikasi
     berbasis feature importance.
6. Evaluasi :
   - Kuantitatif : Accuracy, Precision, Recall, F1-Score, Confusion Matrix,
                  dibandingkan dengan single model baseline.
   - Kualitatif  : Validasi pakar/penyuluh pertanian & User Acceptance Testing.

5. CATATAN KRITIS & HAL YANG PERLU DIPERHATIKAN PADA DOKUMEN PDF
--------------------------------------------------------------------------------
1. Desain Label & Ukuran Sampel (Bagian 3.5.3 & 3.7):
   Perlu diperjelas mekanisme pembentukan pasangan (lokasi + periode -> label
   varietas terbaik) agar tidak terjadi kekurangan sampel atau class imbalance
   pada 25-30 kelas varietas.
2. Skema Split Time-Series (Bagian 3.7):
   Pembagian 80/20 perlu ditegaskan menggunakan chronological/temporal split
   (bukan random split) untuk mencegah data leakage pada LSTM.
3. Konsistensi Wilayah:
   Bagian 1.5 menyebut Provinsi Aceh, Bagian 3.7 menyebut 20 titik di Kabupaten
   Aceh Utara, dan Bagian 3.12 menyebut uji coba di 3 kabupaten.
